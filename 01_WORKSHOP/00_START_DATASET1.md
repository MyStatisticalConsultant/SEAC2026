# Dataset 1 — Start here

For the first hands-on exercise:

1. Open `SEAC2026_Circular_Statistics.Rproj`.
2. Open:
   `01_WORKSHOP/01_Dataset1_Circular_Statistics_BEGINNER.R`
3. Keep the exercise sheet open:
   `01_WORKSHOP/01_Exercise_Dataset1_Circular_Statistics.md`
4. Run the R script one numbered section at a time with **Ctrl+Enter**.
5. Do not type commands directly into the Console unless the instructor asks you to.
6. Files created by the exercise will be saved under:
   `05_OUTPUT/Dataset1/`

The supplied R code is intended to run as written. Sections labelled **CHANGE THIS** contain safe parameters for experimentation.
