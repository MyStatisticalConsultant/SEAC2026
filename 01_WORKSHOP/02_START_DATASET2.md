# Dataset 2 — Start here

**SEAC 2026 workshop — Curvigram and sensitivity analysis**

For the second hands-on exercise:

1. Open `SEAC2026_Circular_Statistics.Rproj`.
2. Open:
   `01_WORKSHOP/02_Dataset2_Curvigram_BEGINNER.R`
3. Keep the exercise sheet open:
   `01_WORKSHOP/02_Exercise_Dataset2_Curvigram.md`
4. Run the R script one numbered section at a time with **Ctrl+Enter**.
5. Sections labelled **CHANGE THIS** contain the parameters you are expected to modify.
6. Do not change the kernel formulas or normalisation code during the workshop.
7. Files created by the exercise will be saved under:
   `05_OUTPUT/Dataset2/`

## Main question

The exercise is not asking:

> Which setting gives the most impressive peak?

It is asking:

> Which features remain substantively stable when reasonable smoothing choices are changed?

That distinction is the central methodological lesson of Dataset 2.
