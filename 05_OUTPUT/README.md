# Workshop outputs

Participant scripts create output files here.

Dataset 1 will create a subfolder:

```text
05_OUTPUT/Dataset1/
```

containing:

- a 300-dpi rose diagram PNG;
- a 600-dpi rose diagram PNG;
- a formatted Word results document.

This folder can be cleared before a fresh workshop run.


## Dataset 2

The curvigram exercise creates:

```text
05_OUTPUT/Dataset2/
```

with:

- baseline and sensitivity numerical CSV files;
- baseline curvigram at 300 and 600 dpi;
- sensitivity-comparison curvigram at 300 and 600 dpi;
- formatted Word results document.

The instructor solution additionally creates a feature-summary CSV used only for validation.


## Dataset 3

The comparative ethnoastronomy exercise creates:

```text
05_OUTPUT/Dataset3/
```

containing:

- subgroup comparison CSV;
- subgroup concentration figure at 300 and 600 dpi;
- pooled/subgroup rose diagrams;
- formatted Word comparison report.
