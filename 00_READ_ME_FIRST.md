# SEAC 2026 — Participant files

Start here:

1. Open `00_WORKSHOP_TIMETABLE_AND_FILE_MAP.md`.
2. Open `SEAC2026_Circular_Statistics.Rproj`.
3. Open `01_WORKSHOP/00_START_HERE.pdf`.
4. Use the files listed for the current session.

## Folder roles

- `01_WORKSHOP/` — participant guide, R scripts and exercises.
- `02_DATA/` — synthetic workshop datasets and their participant-facing data notes.
- `04_REFERENCE/` — reference sheets and infographic posters.
- `05_OUTPUT/` — files generated during the exercises.

Instructor solutions, validation files, technical installation files and development records are intentionally excluded from this participant package.
